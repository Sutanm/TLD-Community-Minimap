# 社区 HUD 地图

[English](README.en.md) · [地图可用性](MAPS.md) · [设置参考](docs/SETTINGS.md) · [当前状态](docs/STATUS.md)

面向《漫漫长夜》的 MelonLoader 地图模组。它把社区制图、游戏原版地图、玩家位置和游戏登记的标记整合到可独立配置的小地图与大地图中。

当前预发布版本：**0.9.0**。目标环境：**The Long Dark 2.55 / Unity 6**、MelonLoader 0.7.2、ModSettings 2.2.5。

## 主要功能

- 小地图与大地图分别选择“自动 / 社区地图 / 原版地图”，并可禁止图源回退。
- 大地图支持地图键接管、滚轮缩放、左键拖动、悬停名称、可选玩家移动和独立置顶。
- 小地图支持四角或自定义位置、尺寸、透明度、缩放和独立置顶。
- 游戏标记可按资源、结构、尸骸、岩石贮藏处和喷漆标记筛选；社区地图游戏标记默认关闭。
- 资源标记跟随采集、随机组和再生状态更新；活体动物不显示为尸骸，大型动物尸体随游戏对象增删。
- 洞穴、矿井和大型室内图可单独启用，多楼层场景按空间区域切图。
- 未可靠校准的复杂地图只显示完整参考图，不显示玩家指针和动态资源标记，避免伪精确定位。
- 木炭勘测后默认打开原版地图，也可改为模组大地图或不打开。

## 安装

1. 安装 MelonLoader 0.7.2 与 ModSettings 2.2.5。
2. 将 `CommunityMinimap.dll` 放入游戏的 `Mods` 目录。
3. 将 `calibrations.json`、`probe-maps.json` 和 `maps` 文件夹放入 `Mods/CommunityMinimap`。
4. 启动游戏，在 ModSettings 的“社区 HUD 地图”中调整选项。

推荐使用发布压缩包中的目录结构。地图素材不提交到源码仓库；制图师 **SValleyFire** 已授权本模组二次分发当前社区地图素材，分发时须保留署名，详见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。

## 默认操作

| 操作 | 默认 |
|---|---|
| 打开/关闭大地图 | 游戏地图键（通常为 `M`） |
| 临时隐藏小地图 | `X` |
| 轮换小地图 / 大地图 / 不显示 | `V` |
| 关闭大地图 | `Esc` |
| 缩放 / 平移 | 鼠标滚轮 / 左键拖动 |
| 捕获原版地图（开发者模式） | `P` |
| 记录校准点（开发者模式） | `F11` |

组合键不会误触发单键轮换，例如 `Ctrl+V` 不会被当作 `V`。

## 设置概览

菜单共 8 个分节、45 个可见选项：

| 分节 | 内容 |
|---|---|
| 通用 | 社区地图游戏标记、洞穴与室内地图、图源回退 |
| 小地图 | 显示、图源、标记大小、置顶、位置、边距、尺寸、透明度、缩放 |
| 大地图 | 接管地图键、图源、标记大小、置顶、玩家指针、背景、鼠标、移动、提示 |
| 玩家指针 | 尺寸与配色 |
| 地图标记与文字 | 数据来源、颜色、描边、地名、字号和悬停提示 |
| 地图标记筛选 | 资源、结构、尸骸、岩石贮藏处、喷漆标记 |
| 按键与游戏联动 | 小地图隐藏、视图轮换、木炭勘测弹图 |
| 高级与开发 | 开发者模式，以及按需显示的抓图、坐标和校准工具 |

所有选项、默认值和行为见 [设置参考](docs/SETTINGS.md)。

## 地图可用性

- **室外地图：22/22** 已捕获原版底图并完成社区图粗校准。
- **洞穴/室内空间：44/44** 已完成场景绑定和处置：稳定区域已校准；无法用单一平面可靠表达的复杂图采用无指针参考模式。
- 污染区集中器已完成实机复查。
- 朗斯顿矿场和远境大型连接洞穴因高度差、分层与社区图形变，不提供误导性的玩家定位。
- 破碎山道等少数社区图存在明显拉伸，仅保证出口与主要地标附近可用。

完整清单和内部文件名见 [MAPS.md](MAPS.md) 与 [粗校准清单](docs/COARSE-CALIBRATION-CHECKLIST.md)。

## 精度与已知限制

原版图源使用游戏自己的投影，位置最可靠。社区地图来自手工绘制，局部可能非均匀拉伸；多点仿射拟合能改善整体方向和比例，却不能消除绘图本身的形变。复杂室内图还可能把不同楼层拼在同一张图中，因此模组宁可降级为参考图，也不显示错误指针。

原版地图图片不会随模组分发。未生成本地捕获图时，模组会读取游戏提供的 1024×1024 区域纹理；它可以应急显示，但内容少于原版面板的完整 2048×2048 地图，并非只有清晰度差异。要生成完整原版图，请暂时关闭“使用模组大地图”，在每个室外区域打开原版地图面板并停留约一秒；模组会自动保存到 `Mods/CommunityMinimap/captured`，之后优先使用。开发者模式的 `P` 可手动重新捕获。

游戏可能把可再生资源生成在不可达地形外；模组目前忠实反映对象状态，没有通用的可达性判定。手柄的大地图缩放与拖动也尚未形成完整方案。

## 构建与发布包

先启动一次游戏以生成 IL2CPP 程序集并安装 ModSettings，然后执行：

```powershell
./build.ps1 -GameDirectory 'D:\SteamLibrary\steamapps\common\TheLongDark'
./package-release.ps1 -GameDirectory 'D:\SteamLibrary\steamapps\common\TheLongDark'
```

构建脚本会拒绝覆盖运行中游戏的 DLL。发布脚本输出到 `dist` 并生成校验和；不会把地图素材加入 Git。
