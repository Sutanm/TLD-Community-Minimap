## 已完成并实测的功能

- 小地图/全屏地图独立图源，自动回退和“禁用回退”。
- 接管游戏地图键；无地图时显示状态提示，不再只释放鼠标却没有反馈。
- 全屏地图平滑缩放、拖动、完整图总览、隐藏玩家指针、洞穴图默认总览。
- 小地图可自定义位置，并可选“始终置顶”；默认允许原版 HUD 覆盖小地图。
- 视图轮换默认改为 `V`，组合键（如 `Ctrl+V`）不会误触发。
- 22 个原版 2048 底图捕获和各自 `.framing` 投影数据。
- 社区地图标记、地名、悬停名称、深色底片、标记描边和小/大地图独立标记尺寸。
- 随机资源组在场景初始化后即时筛选，不再依赖固定三秒等待。
- 采集香蒲、玫瑰果、灵芝、胡须地衣、雪松/冷杉枝干后实时移除标记。
- 大型动物死亡时生成尸骸标记，尸体被游戏回收后移除；活体不再误判为尸骸。
- `MineTransitionZone` 按 Y 高度在沿海公路下层与煤渣山矿洞上层之间自动切图，已实机确认。

## 已知限制

### 社区手绘图的局部形变

粗校准使用多点仿射拟合。它能保证整体方向、比例和地标附近可用，但无法修复原图内部的非均匀拉伸。
寂静河谷、远境支路、中转通道、污染区等复杂图会出现“地标准、道路中段偏”的情况。若以后要提高精度，
需要分区或局部形变模型，而不是继续向同一个全局仿射矩阵盲目加点。

### 地图外随机资源

游戏偶尔会把可再生枝干等资源生成在玩家不可达的地形外。HUD 当前忠实显示游戏中实际存在的对象，
没有可靠且通用的“可达性”判据。这个问题暂缓，社区底图本身可帮助玩家判断异常位置。

### 多楼层组合图

部分室内图把多个楼层或建筑画在同一张图片上。单一 X/Z 仿射投影不能同时表达任意拼接的楼层；粗校准时
先验证能否按高度或空间范围稳定分组。无法稳定分组的图保持开发探针，不强行发布错误指针。

### 手柄

键鼠路径已完成；手柄对全屏图的关闭、缩放和拖动仍未形成完整交互方案。

### 原版迷雾

原版捕获图保存的是捕获当时的面板画面，不会实时重绘勘测迷雾。社区图天然不依赖玩家勘测。
“跟随原版迷雾逐块揭示”仍未实现，也不是当前粗校准阶段的阻塞项。

## 性能与内存

已修复每帧异常、无条件 UI 写入、重复反射本地化和纹理销毁竞态。标记描边仍会为每个图标增加一个
UI 对象，但实测没有证明它是瓶颈。纹理切换使用延迟回收；当前没有证据表明存在持续 OOM 泄漏。
出现异常增长时先按 [PERFORMANCE.md](PERFORMANCE.md) 的方法对照日志和稳定驻留值。
