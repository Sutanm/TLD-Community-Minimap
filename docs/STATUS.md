# 项目状态与发布前清单

> 更新：2026-10-12。以当前代码、`calibrations.json` 和 `probe-maps.json` 为准。

## 当前结论

0.9.0 已进入预发布整理阶段。室外地图主流程、洞穴/室内绑定、分层切换、双图源、全屏交互、HUD 层级、设置菜单、标记筛选及资源/尸骸生命周期都已完成实机验证。集中器已复查，洞穴/室内粗校准阶段结束。

| 范围 | 状态 |
|---|---|
| 原版室外底图 | **22/22 已捕获**（16 主区域 + 6 室外过渡区） |
| 室外社区地图 | **22/22 已粗校准** |
| 洞穴/室内空间 | **44/44 已完成绑定与发布处置** |
| 设置菜单 | **8 分节 / 45 个可见选项** |
| 构建目标 | The Long Dark 2.55 / Unity 6，程序集 0.9.0 |

“完成处置”包括两类：能够稳定映射的空间提供玩家指针与标记；不能用单一 X/Z 平面可靠表达的复杂空间降级为完整参考图，不显示玩家指针或动态标记。

## 已验证能力

- 小地图与大地图独立选择自动、社区或原版图源，并支持禁用回退。
- 大地图缩放、拖动、悬停、可选移动及独立置顶；小地图独立布局与置顶。
- 社区地图标记、地名、分类筛选与小/大地图独立标记尺寸。
- 香蒲、玫瑰果、灵芝、胡须地衣、雪松/冷杉枝干的采集与再生状态同步。
- 活体动物不再误报尸骸；大型尸体生成与系统回收会同步增删标记。
- 多楼层矿井、大坝、监狱和建筑按空间范围切换；楼梯过渡区有稳定的降级处理。
- 未校准复杂图采用无指针、无资源标记的全图参考模式。
- 关闭开发者模式等常规发布配置已由用户实机复查。

## 已知限制

- 社区手绘图存在局部非均匀拉伸，全局仿射拟合无法消除“地标准、道路中段偏”。
- 朗斯顿矿场和远境大型连接洞穴高度变化和图面拼接过于复杂，保留为参考图。
- 游戏偶尔把可再生资源生成在不可达地形外，目前没有可靠的通用可达性判据。
- 原版捕获图保存捕获当时画面，不会实时重绘勘测迷雾。
- 发布包不包含原版地图图片；尚未本地捕获时会回退到内容较少的 1024 区域纹理。完整 2048 图需要玩家逐区域打开一次原版地图面板生成。
- 手柄的大地图缩放、拖动和完整关闭路径仍不如键鼠完善。

## 正式发布前还需完成

1. 用发布压缩包进行一次干净安装冒烟测试：启动、进档、切图源、进出洞穴、打开大地图。
2. 核对第三方地图分发授权和署名文本，并确认发布包没有调试日志、备份或校准截图。
3. 固定 0.9.0 压缩包与 SHA-256 校验和，记录支持的游戏与依赖版本。
4. 收集一轮公开测试反馈后再定 1.0.0；地图册放到 0.9.x/1.0 后续，不阻塞首个公开版本。

发布步骤见 [RELEASE-CHECKLIST.md](../RELEASE-CHECKLIST.md)，地图目录见 [MAPS.md](../MAPS.md)。
