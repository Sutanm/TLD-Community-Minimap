## 地图来源

| 项 | 说明 |
|---|---|
| **小地图图源** | 角落小地图用哪张图。`自动` / `民间高清` / `原版制图` |
| **全屏地图图源** | 全屏地图用哪张图，同上 |

> **两项独立**，各自一份状态。所以"小地图用原版、全屏用社区"是成立的。
>
> **旧键 `MapSource` 已作废**（被拆成上面两项）。`ModSettings` 没暴露存档路径，
> 所以**无法写自动迁移** —— 旧键只是被忽略，重新选一次即可。

### 三种图源的实际含义

| 值 | 贴图 | 标记基准 |
|---|---|---|
| `自动` | 有社区图就用社区图，否则原版 | 跟着实际用哪张走 |
| `民间高清` | `maps/<区域>.jpg` | 仿射校准（**有精度天花板**） |
| `原版制图` | 抓取的真底图（2048），没有则退回 1024 贴图 | **面板实测基准（精确）** |

## 小地图

| 项 | 说明 |
|---|---|
| **显示小地图** | 总开关 |
| **临时隐藏小地图** | 临时用，不改变上面的总开关 |
| **HUD 位置** | 四角或自定义 |
| **自定义位置 X / Y** | `HUD 位置 = 自定义` 时生效 |
| **边距** | 距屏幕边缘的距离 |
| **小地图 UI 大小** | 角落地图的尺寸 |
| **小地图透明度** | 底图不透明度 |
| **局部缩放** | 小地图显示多大的范围（不是完整区域，而是玩家周围一块） |
| **玩家指针尺寸** | 指针三角的大小 |
| **玩家指针配色** | 指针颜色方案 |
| **地图标记尺寸** | 标记图标的屏幕尺寸（**固定值，不随缩放变化**） |
| **标记颜色** | `白色` / `深色`。图集本身是白色图案 |
| **标记描边** | 标记背后加深色轮廓（见下） |

### 关于「地图标记尺寸」与「标记描边」

标记是**固定屏幕尺寸**的，而**社区地图里画的图标是跟着缩放变的**。两者行为不同，
这不是 bug —— 是我们控制不了别人的图。

「标记描边」就是为这个差异准备的：在标记背后加一层大 3 像素的深色副本，
于是白色图标变成"带深色描边"，**在浅色羊皮纸和深色地形上都能看清**。

> **代价**：社区图上标记对象数量翻倍（802 → 1604）。
> 关掉它则回到纯色图标、802 个对象。

## 地图标记筛选

| 项 | 说明 |
|---|---|
| **标记来源** | `地图数据`（默认，**802 个**）/ `游戏面板`（旧做法，**只有 162 个**） |
| **社区地图上也画标记** | 默认开。标记会用**社区图的基准**重新投影 |
| **地名标签** | 显示地图上的地名（区域自带，14 个） |
| **悬停显示图标名字** | 鼠标停在**图标**上显示名字。**地名不参与悬停**（它的名字本来就在图上） |
| **标记字号** | 地名与悬停提示的字号 |
| **悬停提示的深色底片** | 提示文字背后的深色方块，可关 |
| **资源 / 结构 / 尸骸 / 岩石贮藏处 / 油漆喷罐标记** | **游戏自己的 5 个分类**，按 sprite 名归类 |

### 关于「标记来源」

- **`地图数据`**：读 `MapDetailManager.s_MapDetails`，本地区 **802 个**全画，位置走与校准相同的坐标系
- **`游戏面板`**：旧做法，只刮取游戏**实际实例化**的那部分（**162 个**）

> 上限差异是**结构性的** —— 游戏只建 162 个，刮取永远超不过它。
> 所以默认是 `地图数据`。**标记画得不对时切回旧做法即可。**

### 分类是按 **sprite 名**，不是 `m_IconType`

`m_IconType` 只表示**绘制尺寸**（同一图标的大/中/小变体），**与类别无关**。

无法归类的 sprite 名进 `Unclassified`，**始终绘制** —— 猜一个类别会**静默隐藏**一类标记，
那正是这次重写要修的毛病。

## 全屏地图（按游戏地图键打开，默认 M）

| 项 | 说明 |
|---|---|
| **全屏背景不透明度** | 地图背后的遮罩 |
| **接管游戏地图键** | 按 M 打开我们的地图而不是游戏的 |
| **释放鼠标（缩放与拖动）** | 打开时释放鼠标；**悬停提示依赖它** |
| **按键提示** | 底部那行操作提示 |
| **抓取游戏地图的键** | 默认 `P`（见 [STATUS.md](STATUS.md) §1） |
| **木炭勘测后弹图** | 游戏勘测完弹出地图时，短暂让游戏自己显示（默认行为，见下） |

### 关于「木炭勘测后弹图」

游戏在**木炭勘测完成后**会弹一次自己的地图面板，用来显示"你勘测到了什么"。
我们**短暂让游戏显示**（默认 3 秒），否则那次弹图会变成我们的地图，玩家看不到勘测反馈。

## 高级

| 项 | 说明 |
|---|---|
| **开发者模式** | 打开各种普查/探针的日志与导出 |
| **启用视图轮换按键** | 用按键在小地图/全屏/不显示之间循环 |
| **视图轮换按键 / 轮换内容** | 上者的键位与循环内容 |
| **显示坐标诊断** | 屏幕上的坐标读数 |
| **记录校准点** | 按一次记录一个校准点（默认 `F11`） |
| **清理已采集的标记（仅报告）** | **只写日志，不隐藏** —— 用来观察判据 |
| **真正删除已采集标记** | **实际隐藏**已采集的标记 |

> ⚠️ **最后两项要小心。** 判据（`m_HarvestablesForMapVisibility`）只覆盖
> **136 / 802** 条，对剩下的 666 条**无效**。所以"真正删除"只在有那 136 条数据的地方起作用，
> 详见 [STATUS.md](STATUS.md) §4.2。

## 按键默认值

| 键 | 作用 |
|---|---|
| `M` | 打开全屏地图（`接管游戏地图键` 开启时） |
| `X` | 小地图总开关 |
| `Tab` | 视图轮换（需先启用 `启用视图轮换按键`） |
| `P` | **抓取游戏地图**（`抓取游戏地图的键`） |
| `F11` | 记录校准点（`记录校准点`） |
| `Esc` | 关闭全屏地图 |
