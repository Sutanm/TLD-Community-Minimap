# 设置参考

> 更新：2026-10-12 · 当前为 **8 个分节 / 45 个可见选项**。
>
> 配置文件：`<游戏目录>\Mods\CommunityMinimap.json`。字段名是持久化键；界面中文名称可以调整，
> 但代码字段名不能随意改，否则会重置玩家已有设置。

界面统一使用“小地图 / 大地图”“社区地图 / 原版地图”。小地图与大地图节点的共同选项按相同顺序排列：开关、图源、标记大小、始终置顶。

## 通用

| 项 | 默认 | 说明 |
|---|---:|---|
| 社区地图显示游戏标记 | 关 | 在已校准的社区地图上显示游戏标记 |
| 启用洞穴与室内地图 | 开 | 在洞穴、矿井和室内场景启用本模组地图 |
| 禁用图源回退 | 关 | 所选图源不可用时不切换图源 |

## 小地图

| 项 | 默认 | 说明 |
|---|---:|---|
| 显示小地图 | 开 | 不影响大地图 |
| 小地图图源 | 自动 | 自动 / 社区地图 / 原版地图 |
| 小地图标记大小 | 44 px | 固定屏幕尺寸 |
| 小地图始终置顶 | 关 | 显示在游戏 HUD 上方 |
| 小地图位置 | 左上 | 右上 / 左上 / 右下 / 左下 / 自定义 |
| 自定义位置 X / Y | 50% / 50% | 仅自定义位置时显示 |
| 边距 | 24 | 仅四角位置时显示 |
| 小地图大小 | 24% | 占屏幕短边比例 |
| 小地图透明度 | 90% | 只影响小地图 |
| 小地图缩放 | 5.0x | 已校准地图的局部视野 |

## 大地图

| 项 | 默认 | 说明 |
|---|---:|---|
| 使用模组大地图 | 开 | 游戏地图键打开本模组大地图 |
| 大地图图源 | 自动 | 自动 / 社区地图 / 原版地图 |
| 大地图标记大小 | 44 px | 固定屏幕尺寸 |
| 大地图始终置顶 | 关 | 显示在游戏 HUD 上方 |
| 显示玩家指针 | 开 | 显示玩家位置和朝向 |
| 背景不透明度 | 97% | 大地图周围的深色背景 |
| 启用鼠标操作 | 开 | 滚轮缩放、左键拖动和标记悬停 |
| 允许打开时移动 | 关 | 允许角色移动，仍阻止转向、攻击和交互 |
| 显示操作提示 | 开 | 显示底部操作提示 |

洞穴/室内图默认以完整图总览打开，最小缩放允许到 0.35x；室外大地图仍优先从玩家附近打开。

选择原版图源时，本地捕获的 2048 面板图优先于游戏内置的 1024 区域纹理。后者内容不完整，只作无捕获文件时的回退。发布包不包含原版图片；玩家可暂时关闭“使用模组大地图”，在每个室外区域打开原版地图面板约一秒，让模组自动生成本地捕获图。

## 玩家指针

| 项 | 默认 | 说明 |
|---|---:|---|
| 玩家指针尺寸 | 54 | 圆环、中心点与方向短针的整体尺寸 |
| 玩家指针配色 | 珊瑚红 | 六种强调色 |

## 地图标记与文字

| 项 | 默认 | 说明 |
|---|---:|---|
| 标记来源 | 地图数据 | 完整登记数据；“游戏面板”只读取面板实际创建的部分 |
| 标记颜色 | 白色 | 白色 / 深色 |
| 标记描边 | 开 | 增加一个深色垫底对象，提高不同底色上的可见性 |
| 地名标签 | 开 | 显示游戏登记的地点名称 |
| 标签字号 | 20 | 地名和悬停名称字号 |
| 悬停显示标记名称 | 开 | 大地图鼠标悬停时显示名称 |
| 悬停提示背景 | 开 | 为悬停提示添加深色背景 |

## 地图标记筛选

五个开关默认都开启：资源、结构、尸骸、岩石贮藏处、油漆喷罐标记。分类依据是图标 sprite 名，
不是 `m_IconType`；后者只表示游戏绘制尺寸。

资源和尸骸还会经过运行时状态过滤：未启用的随机资源组不显示，已采集资源和已回收尸骸会移除，
活体动物不显示为尸骸。

## 按键与游戏联动

| 项 | 默认 | 说明 |
|---|---:|---|
| 临时隐藏小地图 | `X` | 不改保存设置，也不影响大地图 |
| 启用视图轮换按键 | 开 | 允许独立按键轮换视图 |
| 视图轮换按键 | `V` | 组合键不会触发；`V` 不与游戏默认“显示时间”冲突 |
| 轮换内容 | 小地图→大地图→无 | 另有三种循环组合 |
| 木炭勘测后弹图 | 原版地图 | 原版地图 / 模组大地图 / 不打开 |

## 高级与开发

开发者模式默认关闭；关闭时其余三项隐藏但保留设置值。

| 项 | 默认 | 说明 |
|---|---:|---|
| 开发者模式 | 关 | 显示捕获、诊断和校准工具；不控制正常洞穴/室内地图 |
| 抓取原版地图 | `P` | 保存当前原版地图供校准使用 |
| 显示坐标诊断 | 关 | 显示场景、世界坐标与朝向 |
| 记录校准点 | `F11` | 写入校准 CSV/截图，供网页校准器使用 |
旧版“清理已采集的标记（仅报告）”字段只为兼容已有配置保留，不再显示在设置面板。

## 默认按键汇总

| 键 | 作用 |
|---|---|
| 游戏地图键（通常 `M`） | 打开/关闭大地图 |
| `X` | 临时隐藏小地图 |
| `V` | 轮换视图 |
| `Esc` | 关闭大地图 |
| `P` | 捕获原版地图（开发者） |
| `F11` | 记录校准点（开发者） |
