# 设置参考

> 更新：2026-10-07 · 当前为 **8 个分节 / 44 项**。
>
> 配置文件：`<游戏目录>\Mods\CommunityMinimap.json`。字段名是持久化键；界面中文名称可以调整，
> 但代码字段名不能随意改，否则会重置玩家已有设置。

## 基本与图源

| 项 | 默认 | 说明 |
|---|---:|---|
| 显示小地图 | 开 | 角落 HUD 总开关，不影响地图键打开的全屏图 |
| 接管游戏地图键 | 开 | 跟随游戏自己的地图键绑定；关闭后恢复原版行为 |
| 小地图图源 | 自动 | 自动 / 民间高清 / 原版制图 |
| 全屏地图图源 | 自动 | 与小地图独立选择 |
| 禁用图源回退 | 关 | 明确选定图源不可用时不再临时切到另一套；“自动”不受影响 |

## 小地图

| 项 | 默认 | 说明 |
|---|---:|---|
| HUD 位置 | 左上 | 右上 / 左上 / 右下 / 左下 / 自定义 |
| 自定义位置 X / Y | 50% / 50% | 仅自定义位置时显示 |
| 边距 | 24 | 仅四角位置时显示 |
| 小地图 UI 大小 | 24% | 占屏幕短边比例，与地图局部缩放分开 |
| 小地图透明度 | 90% | 只影响小地图图片 |
| 小地图始终置顶 | 关 | 开启后恢复旧行为：小地图覆盖原版 HUD |
| 局部缩放 | 5.0x | 玩家位于已校准范围时的局部视野 |
| 小地图标记尺寸 | 44 px | 固定屏幕尺寸，不随地图缩放改变 |

## 全屏地图

| 项 | 默认 | 说明 |
|---|---:|---|
| 全屏背景不透明度 | 97% | 完整地图周围的深色遮罩 |
| 释放鼠标（缩放与拖动） | 开 | 开启后接管滚轮、左键和悬停 |
| 按键提示 | 开 | 显示底部操作提示 |
| 全屏地图标记尺寸 | 44 px | 与小地图标记尺寸独立 |

洞穴/室内探针图默认以完整图总览打开，最小缩放允许到 0.35x；室外大地图仍优先从玩家附近打开。

## 玩家指针

| 项 | 默认 | 说明 |
|---|---:|---|
| 玩家指针尺寸 | 54 | 圆环、中心点与方向短针的整体尺寸 |
| 玩家指针配色 | 珊瑚红 | 六种强调色 |
| 全屏地图显示玩家指针 | 开 | 关闭时只隐藏全屏指针，并从整张图中央打开；小地图不受影响 |

## 地图标记与文字

| 项 | 默认 | 说明 |
|---|---:|---|
| 标记来源 | 地图数据 | 完整登记数据；“游戏面板”只读取面板实际创建的部分 |
| 社区地图上也画标记 | 开 | 在手绘图上按社区校准重新投影 |
| 标记颜色 | 白色 | 白色 / 深色 |
| 标记描边 | 开 | 增加一个深色垫底对象，提高不同底色上的可见性 |
| 地名标签 | 开 | 显示游戏登记的地点名称 |
| 标记字号 | 20 | 地名和悬停名称字号 |
| 悬停显示图标名字 | 开 | 只在释放鼠标的全屏图上生效 |
| 悬停提示的深色底片 | 开 | 关闭后只保留带浅色阴影的文字 |

## 地图标记筛选

五个开关默认都开启：资源、结构、尸骸、岩石贮藏处、油漆喷罐标记。分类依据是图标 sprite 名，
不是 `m_IconType`；后者只表示游戏绘制尺寸。

资源和尸骸还会经过运行时状态过滤：未启用的随机资源组不显示，已采集资源和已回收尸骸会移除，
活体动物不显示为尸骸。

## 按键与游戏联动

| 项 | 默认 | 说明 |
|---|---:|---|
| 临时隐藏小地图 | `X` | 不改保存设置，也不影响全屏图 |
| 启用视图轮换按键 | 开 | 允许独立按键轮换视图 |
| 视图轮换按键 | `V` | 组合键不会触发；`V` 不与游戏默认“显示时间”冲突 |
| 轮换内容 | 小地图→大地图→无 | 另有三种循环组合 |
| 木炭勘测后弹图 | 当前图源 | 游戏内置 / 当前图源 / 不弹 |

## 高级与开发

开发者模式默认关闭；关闭时其余四项隐藏但保留设置值。

| 项 | 默认 | 说明 |
|---|---:|---|
| 开发者模式 | 关 | 启用捕获、诊断、探针地图和校准工具 |
| 抓取游戏地图的键 | `P` | 在原版地图面板打开时捕获 2048 图和 `.framing` |
| 显示坐标诊断 | 关 | 显示场景、世界坐标与朝向 |
| 记录校准点 | `F11` | 写入校准 CSV/截图，供网页校准器使用 |
| 清理已采集的标记（仅报告） | 关 | 历史诊断项，只写日志；HUD 本身已自动隐藏已采集资源 |

最后一项名称容易误解，但保留字段是为了兼容已有配置。它不是功能开关，也不会删除游戏存档数据。

## 默认按键汇总

| 键 | 作用 |
|---|---|
| 游戏地图键（通常 `M`） | 打开/关闭全屏地图 |
| `X` | 临时隐藏小地图 |
| `V` | 轮换视图 |
| `Esc` | 关闭全屏地图 |
| `P` | 捕获原版地图（开发者） |
| `F11` | 记录校准点（开发者） |
