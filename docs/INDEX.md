## 文档纪律

1. **结论必须带证据**。写"实测"就要能指出日志行、数字或代码位置。
2. **AI 推断要标注**。凡是没有实测支撑的判断，写「来源：AI 推断」。
3. **否定的结论同样要记**，而且要写得比肯定的结论更醒目 —— 例如
   "不存在大于 1024 的区域贴图"是花了几轮枚举才得到的，能省掉后人重复枚举。
4. **过时不是删除的理由**，但要显式标注状态。
